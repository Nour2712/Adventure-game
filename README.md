Adventure Time

Et tekstbaseret adventure spil i Java
Spilleren går rundt i 9 rum, kan samle ting op, spise mad, bruge våben og kæmpe mod fjender.

Sådan starter du spillet:
Åbn projektet i IntelliJ og kør Main.java.

Kommandoer:
n, e, s, w - gå nord, øst, syd eller vest
look - se hvad der er i rummet
take <item> - saml en ting op
drop <item> - læg en ting fra dig
inventory - se hvad du bærer på
eat <item> - spis noget mad
health - se dit helbred
equip <weapon> - gør et våben klar
attack <enemy> - angrib en fjende
help - vis alle kommandoer
exit - afslut spillet

Klassediagram og aktivitetsdiagram ligger i docs mappen.
